# 🕵️ 谁是卧底 · 传阅手机版

一个无需联网、单文件的「谁是卧底」游戏，专为家庭聚会设计：**一部手机轮流传阅看词即可开局**。

👉 在线试玩（开启 GitHub Pages 后）：`https://<你的用户名>.github.io/zhuanpan/spy/`

## 特点

- **零依赖、纯前端**：只有一个 `index.html`，离线也能玩。
- **传阅看词**：每位玩家轮流轻触屏幕私密查看自己的词，看完传给下一位。
- **可调玩法**：3–20 人、1 至多名卧底、可选「白板」角色。
- **内置词库**：食物 / 动物 / 生活 / 娱乐 / 场景 5 大类，可多选；也支持自定义词。
- **辅助流程**：自动生成发言顺序、投票出局标记、一键揭晓答案。
- **记住偏好**：人数、卧底数、分类等设置存在本机（localStorage）。

## 玩法

1. **设置**：选人数、卧底数，是否加白板，选词库分类或自定义词，可填名字。
2. **发牌**：点「开始发牌」，把手机依次交给每位玩家，私密查看各自的词。
3. **发言**：按屏幕给出的顺序，每人用一句话描述自己的词（不能直接说出来）。
4. **投票**：怀疑谁是卧底就投谁出局，在名单里标记。
5. **揭晓**：点「揭晓答案」查看卧底身份与两个词，再换词来一局。

> 卧底拿到的是与平民相近但不同的词；白板则没有词，全靠观察混进去。

## 在 GitHub Pages 发布

1. 把本仓库推送到 GitHub。
2. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`（或你的发布分支），目录 `/ (root)`，保存。
3. 等待生效后访问 `https://<用户名>.github.io/zhuanpan/spy/` 即可。
